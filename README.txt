# Hướng dẫn chạy ứng dụng Electron

1. Mở Command Prompt và chuyển vào thư mục electron-app:
   cd electron-app

2. Cài đặt các gói cần thiết:
   npm install

3. Chạy ứng dụng:
   npm start

Ứng dụng sẽ mở ra cửa sổ desktop với nút "Chạy Script". Bạn có thể thay nội dung file ThaiAsia-AllInOne.js bằng code thật của bạn.
